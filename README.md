# 持仓体检卡 TickerCheck

> **5 个可核实指标，3 分钟体检你的持仓，数据全程不出本机。**
> 本地 Python 工具，开源、免费、无需联网、不收集任何数据。

输入一份持仓 CSV，输出一份**单文件自包含 HTML 体检报告**（内嵌 CSS、无外部资源、响应式）。

定位：**数据体检工具，不是荐股工具**。只输出结构化评分、事实性风险标记与「下一步核查清单」，不出现任何买入/卖出/加仓/减仓表述。

---

## 1. 30 秒跑起来

依赖：Python 3.9+（仅标准库，无需 pip install）

```bash
cd tickercheck

# ① 生成示例报告（内置**指数化虚构**样本，可公开展示）
python -m tickercheck.cli -i samples/holdings.csv -o out/report.html --as-of 2026-09-12

# ② 换成你自己的持仓（先复制模板，示例行删掉）
cp samples/template.csv my.csv
python -m tickercheck.cli -i my.csv -o out/my-report.html --as-of 2026-09-12

# ③ 自检（12 项）
python -m tests.selftest

# ④ 批量跑批：一键生成报告 + 回传模板 + 自动记账（秒级/份）
python -m scripts.batch --inbox submissions --outdir out/batch --as-of 2026-09-12 --week W1

# ⑤ 人工判定补记（脚本不代判「是否陌生」）
python -m scripts.batch --mark "demo_valid:real" --week W1

# Windows 双击一键跑：run.bat（自检 → 样例报告 → 批量跑批）
```

`--as-of` 是**数据截止日期**，公开报告必填；不填会在报告中显示「未标注」并在命令行报警。
`--source` 可改数据来源标注，默认「本地 CSV（用户提供）」。

跑完打开 `out/report.html` 即可。报告可直接双击、可发给别人、可截图当内容素材。

## 2. 输入格式（CSV，UTF-8，第一行为表头）

| 列名 | 必填 | 含义 | 缺失时 |
|---|---|---|---|
| `code` | ✅ | 代码 | — |
| `name` | ✅ | 名称 | — |
| `sector` | ✅ | 行业/标签，用于行业集中度 | 填「未分类」 |
| `shares` | ✅ | 持仓数量 | — |
| `cost` | ✅ | 成本价（每股） | — |
| `price` | ✅ | 现价（每股） | — |
| `pe` | 选填 | 市盈率（亏损填负数） | 按中性分 50 处理并标注 |
| `pb` | 选填 | 市净率 | 同上 |
| `roe` | 选填 | 净资产收益率 % | 同上 |
| `profit_yoy` | 选填 | 净利同比 % | 同上 |
| `revenue_yoy` | 选填 | 营收同比 % | 同上 |
| `debt_ratio` | 选填 | 资产负债率 % | 同上 |
| `vol_annual` | 选填 | 年化波动率 % | 同上 |

**缺失字段不会被猜数**，一律按中性分并在报告里标注「数据缺失」——宁可暴露缺失，也不制造假精确。ETF 可以只填必填 6 列。

## 3. 评分口径（可改，规则全在 `tickercheck/engine.py`）

个券四维（市值加权）→ 组合结构分 → 综合分

| 维度 | 权重 | 看什么 |
|---|---|---|
| 估值 | 30% | PE / PB 分档，负 PE 明确给低分 |
| 成长 | 20% | 净利同比、营收同比 |
| 质量 | 30% | ROE、资产负债率 |
| 风险 | 20% | 年化波动率 |
| 结构 | 15%（组合层） | HHI 集中度、第一大持仓占比、最大行业占比 |

评级：≥80 健康 / ≥65 基本健康 / ≥50 亚健康 / ≥35 预警 / <35 高危

**配色约定**：涨跌用红涨绿跌（中国市场习惯）；评分为语义色（青→绿→琥珀→红），两者含义互不干扰。

## 5. 创始人假设清单（拍板时明写，后续用事实验证）

| # | 假设 | 若不成立的应对 |
|---|---|---|
| A1 | 启动预算 0 元 | 若需数据 API 付费，先退回「手工填 CSV」 |
| A2 | 每周 2 小时 × 12 周 | 若某周中断，跳过不补，直接进入下一周期 |
| A3 | 自用即验证（创始人本人是目标用户） | 若自己两周内不用第二次，说明方向错，转向内容工具 |
| A4 | 渠道 = 已有每周 AI 视频账号 | 若该账号不适合，改用纯图文长文，不新开阵地 |
| A5 | 合规底线：只体检不建议 | 若投资人反馈只要结论，坚持不做，宁可慢 |
| A6 | 12 周成功标准：1 个真实陌生人主动索取报告 | 若未达成，判定为渠道问题而非产品问题，换分发形态重来 |

## 6. 合规红线（硬性，不可绕过）

❌ 禁止：买卖建议 / 目标价 / 仓位建议 / 评级词（买入·增持·持有·减持·卖出）/ 收益承诺 / 公开点评任何具体个股
✅ 只允许：可核实的客观指标、规则化打分（标清口径与权重，声明"非评级"）、结构化核查清单

三条自动执行的约束：

1. **样本必须去标识化**：`samples/holdings.csv` 已改为**指数化虚构**持仓（IDX300 等），可直接公开展示。任何对外样本**不得出现真实个股名 + 具体估值数字**。
2. **每份报告必须标注**「数据来源 + 数据截止 + 生成时间」——已写进 `report.py` 页眉，`--as-of` 未填会显式报警。
3. **不托管、不留存、不展示任何真实持仓数据**：本地跑、本地存、处理完即删。

若平台限流或出现合规压力：**整体后撤到「方法与工具」层**——只讲"如何用 5 个可核实指标做持仓自检"这类方法论，一对一报告仅私发本人，永不公开展示。

## 7. 声明

本工具输出的是基于用户输入数据的结构化体检结果，仅用于信息整理与自我核查，**不构成投资建议、买卖依据或任何形式的收益承诺**。所有评分为规则化计算的参考值，不预测未来走势。
