5 个可核实指标，3 分钟体检你的持仓。工具在你自己电脑上跑，持仓数据永远不会离开你的电脑，也不会被任何人收集。

输入一份持仓 CSV，生成一份单文件 HTML 体检报告：五维评分、持仓明细、风险标记、下一步核查清单。

三步跑起来

  1. 安装 Python 3.9+（python.org，点下一步即可），无需装任何其他东西
  2. git clone https://github.com/xuebajunzhu/tickercheck 然后 cd tickercheck
  3. python -m tickercheck.cli -i samples/holdings.csv -o out/report.html --as-of 今天

打开 out/report.html（双击、不用联网）。换成自己的持仓：复制 samples/template.csv 照填即可。
