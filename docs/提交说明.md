# 提交说明（发给索取者）

## 你要给我什么（二选一）

**方式 A：填 CSV（推荐）**
下载 `samples/template.csv`，按行填，至少 3 个标的：

| 列名 | 必填 | 说明 |
|---|---|---|
| `code` | ✅ | 代码（不想写真名就写自定义代号） |
| `name` | ✅ | 名称（可用代号，如"宽基A"） |
| `sector` | ✅ | 行业/分类（如 宽基 / 科技 / 医药 / 消费） |
| `shares` | ✅ | 持仓数量 |
| `cost` | ✅ | 成本价（每股） |
| `price` | ✅ | 现价（每股） |
| `pe` `pb` `roe` `profit_yoy` `revenue_yoy` `debt_ratio` `vol_annual` | 选填 | 填了更准，不填按中性处理并标注 |

**方式 B：纯文本**
直接发 3 行以上，每行：`代码 名称 分类 数量 成本价 现价`

## 我不收什么

- ❌ 不收任何账号、密码、身份证、手机号
- ❌ 不需要真实姓名——名称栏写代号即可
- ❌ 不需要资金账号截图

## 数据怎么处理

- 报告在**本地生成**，不联网、不上传
- 处理完报告发你之后，CSV 由你自己决定是否删除——**我这边不留档**
- 你提交的任何内容都不会被公开发布或展示

## 你会拿到什么

一个 HTML 文件，双击打开：

- 综合评分与五维拆解（估值 / 成长 / 质量 / 风险 / 结构）
- 持仓明细表（权重、盈亏、个券评分）
- 风险标记（事实陈述，如"第一大持仓占比 41%，超过 35% 阈值"）
- 下一步核查清单

## 它不是什么

- 不是评级，不含买入/卖出建议、不含目标价
- 不预测涨跌，不承诺任何收益
- 数据准确与否取决于你填的内容

---
本工具输出仅供数据核查参考，不构成投资建议。
