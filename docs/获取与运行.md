# 获取与运行（陌生人版）

这份说明写给第一次看到本工具、想自己体检持仓的人。全程在你自己电脑上完成，**不需要把任何持仓数据发给任何人**。

## 前置

- 装一个 Python（3.9 及以上，点下一步装完即可，官网 python.org）
- 不需要装任何其他东西，本工具只用 Python 自带功能

## 三步

```bash
# 1. 拿到代码（任选其一）
git clone <本仓库地址>
# 或：直接在页面下载 ZIP，解压

# 2. 进入目录
cd tickercheck

# 3. 生成你的报告
python -m tickercheck.cli -i samples/holdings.csv -o out/report.html --as-of 2026-09-12
```

打开 `out/report.html`（双击即可，不用联网）就能看到报告。

## 换成你自己的持仓

1. 复制模板：`cp samples/template.csv my.csv`
2. 用记事本打开 `my.csv`，按表头填：至少 3 个标的，每只填**数量、成本价、现价**
3. 跑：`python -m tickercheck.cli -i my.csv -o out/my-report.html --as-of 今天日期`
4. 报告里不想填的指标（PE/PB/ROE 等）留空即可，工具会按中性分处理并标注

## 不想填数据怎么办

报告页眉必须填 `--as-of`（数据截止日期），否则会提示"未标注"。

## 它是工具，不是建议

- 输出是规则化打分的结构化体检，不含买入/卖出建议、不含目标价、不含评级词
- 不预测涨跌，不承诺收益
- 数据准确性取决于你填的内容；工具只算，不查

本工具输出仅供数据核查参考，不构成投资建议。
