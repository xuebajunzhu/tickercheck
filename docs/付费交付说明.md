> 配套站点页：`docs/pricing.html`（已部署到 GitHub Pages）。

## 1. 产品定位：免费做"体检"，付费做"读片"

TickerCheck 的价值链分两层，对应两种边际成本：

| 层 | 谁来做 | 内容 | 边际成本 |
|---|---|---|---|
| 免费 | 机器（本地规则引擎） | 五维打分、明细、风险标记、核查清单 | 0（自助） |
| 付费 | AI 辅助 + 创始人专业判断 | 把分数翻译成"人话 + 边界 + 行动清单" | 低（模板 + 模型，创始人只审） |

关键判断：**机器能自动打的分，全部免费**；只有"机器打不准、需要人来判断"的解读环节，才是付费层。这样既守住"免费工具"的引流钩子，又把付费点落在 AI + 人不可替代的地方。

---

## 2. 三层定价（草拟）

| 层 | 名称 | 价格 | 交付物 | 说明 |
|---|---|---|---|---|
| Tier 0 | 本地体检卡 | ¥0 | 五维规则化打分，单文件 HTML | 引流钩子，零成本 |
| Tier 1 | 深度解读报告 | ¥49 / 次 | AI+专业判断二次解读，单文件 HTML | 主付费品 |
| Tier 2 | 报告 + 答疑 | ¥99 / 次 | Tier1 全部 + 1 次 15 分钟异步文字答疑 | 高客单、低频 |

价格逻辑：
- 低客单、单次、无订阅——降低零渠道下的决策门槛（R1 信任壁垒）。
- 暂不设"季度跟踪"订阅：每周 2 小时约束下，订阅=持续履约压力，验证出稳定需求后再考虑。

## 3. 付费报告交付清单

**包含（交付物）：**
1. 五维分数的**白话解读**（不是复述数字，是"这说明什么"）
2. 风险点定位 + 严重度分级（哪些该先研究）
3. 与你自查基准的偏差提示
4. 个性化"下一步核查清单"（回答"我现在该做什么核查"）
5. 明确标注的边界与适用场景
6. 你本机生成报告的二次加工（不另要原始数据）

**不含（红线）：**
- 任何买卖建议、收益或回撤承诺
- 个股评级、"该买/该卖"结论
- 与免费工具一致：仅用于信息整理与自我核查

---

## 4. 交付流程

**用户侧（①）：**
1. 本机跑免费工具 → 得到 `report.html`
2. 申请页提交 `report.html` + 一句自查目标
3. 收到单文件 HTML 深度报告
4. （¥99 档）7 天内文字追问一次

**创始人侧（② · AI 辅助）：**
1. 收到报告，喂入"结构化解读模板 + LLM"
2. AI 产出解读骨架（翻成可读文本）
3. 创始人逐条核对、加专业判断、删错漏
4. 导出单文件 HTML，24–48h 内交付

> 一个人、每周 2 小时也能交付：重活交给模板和模型，创始人只做"判断准不准、边界清不清"的审阅。

---

## 5. 数据边界与信任红线

这是整个付费模型的**命门**，必须公开、显眼：

- **免费工具**：数据全程不出本机、不联网、不收集（铁承诺）。
- **付费服务**：需要用户**主动提交**本机生成的 `report.html`，意味着数据会离开用户电脑进入交付流程——这是用户知情同意下的选择，不是偷偷上传。
- **交付后**：报告文件即删、不留存、不用于任何其他用途。
- **合规**：付费报告同样不含任何买卖建议，与免费工具同一红线。

若未来做"完全本地化的付费解读"（用户用自己的本地 AI 跑模板，数据不出机），可进一步消解此边界，作为后续方向。

## 7. 上线节奏与验证计划

**阶段 A — 手动验证（现在）：**
- 不接支付。前 5 单用手动流程跑，暂不收费，换一句真实反馈。
- 观测指标：**申请率**（跑免费工具的人里多少来要深度报告）、**愿意付费比例**（告知价格后是否仍要）。
- 判定：申请率 ≥ 某阈值 且 愿意付费 > 0，进入阶段 B。

**阶段 B — 自动申请 + 支付：**
- 上线申请页（表单提交 report.html + 目标）。
- 接轻量支付（如微信赞赏/支付链接或 Stripe 个人档），创始人侧流水线不变。
- 监控交付时效（24–48h）与反馈质量。

**阶段 C — 扩品（验证后）：**
- 若深度报告稳定有需求，再考虑"季度跟踪"订阅或行业模板包。

## 8. 风险与未决

- **信任成本**：付费需离机，可能劝退最在意隐私的用户。缓解：透明告知 + 交付即删 + 未来本地化解读方向。
- **单人产能**：AI 辅助后单人可交付，但需求集中时会有排队。缓解：明确 24–48h 时效、限量接单。
- **合规一致性**：付费报告必须和免费工具一样守红线，避免被解读为投顾。模板与交付物需内置免责声明。
- **价格未验证**：¥49 / ¥99 为草拟，阶段 A 用"告知价格后是否仍要"来校准。
